# API Fat Trim — Quality & Architecture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove excess work, leaky internals, god-module structure, and misplaced helpers before frontend — **without deleting any locked v1 product features or metrics.**

**Architecture:** Second fat pass (quality / architecture). Product surface stays. Changes: (1) one holdings pass for performance, (2) flatter performance JSON, (3) archive spent plans, (4) lean UI constraints, (5) typed internal holding row (kill `_benchmark_cagr` leak), (6) batch DB loads + shared txn map (kill N+1 and double txn scan), (7) split `portfolio.py` into data / windows / service, (8) move KV settings out of `kite_auth`, (9) delete dead schema + unify price upsert + relocate `INDEX_TICKERS`, (10) DRY integration test seeds.

**Tech Stack:** FastAPI, SQLAlchemy 2.0, SQLite, pytest, `uv`; docs under `docs/superpowers/`.

## Global Constraints

- **No feature removal.** Keep: ITD + 1Y/3Y/5Y; absolute / XIRR / CAGR; all three excess types; same-cashflow benchmark XIRR; Console EQ+MF CSV; Kite sync; Yahoo+AMFI; gap+reconcile; Settings overrides; multi-file import
- Public HTTP response **field names** for overview/holdings stay compatible (top-level ITD fields on holdings remain — Holdings table needs them). Performance may drop nested `overview` (Task 2) because web is unbuilt
- Rates = fractions; excess = percentage points
- Secrets never committed; no real Zerodha keys in CI
- Every task ends green: `cd apps/api && uv run pytest -q`
- Prefer edit/split over rewrite; do not change metric formulas

```python
def _load_transactions_by_instrument(
    session: Session, as_of: str
) -> dict[int, list[Transaction]]:
    rows = (
        session.query(Transaction)
        .filter(Transaction.trade_date <= as_of)
        .order_by(Transaction.trade_date.asc())
        .all()
    )
    out: dict[int, list[Transaction]] = {}
    for tx in rows:
        out.setdefault(tx.instrument_id, []).append(tx)
    return out


def _load_snapshots(session: Session) -> dict[int, HoldingsSnapshot]:
    return {
        snap.instrument_id: snap
        for snap in session.query(HoldingsSnapshot).all()
    }
```
